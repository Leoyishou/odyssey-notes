# 🪞Notes

**不一样，但都能让外面的设备连接到电脑上的服务。**

| | cloudflared | Tailscale |
|---|---|---|
| 主要用途 | 把某个本地服务通过 Cloudflare 隧道提供出去 | 把你的设备组成一个私有网络 |
| 手机如何访问 | 访问隧道网址，是否需要登录取决于配置 | 通常手机和电脑都安装并登录 Tailscale |
| 连接方式 | 经过 Cloudflare 隧道 | 优先设备直连，无法直连时经中继 |
| 常见场景 | 网站、应用入口、远程访问 | 个人设备互联、远程开发、访问家中电脑 |

放到你的 T3 场景：**cloudflared 是为 T3 服务建立隧道；Tailscale 是先连通手机和电脑，再访问 T3。**

但 **Tailscale 不等于能绕过公司的限制**。公司也可能限制它；你截图只证明 `cloudflared` 被禁用了，不能据此判断 Tailscale 是否被允许。
