## 访问其他 App 数据

![CleanShot 2026-11-22 at 14.17.33@2x.png|1000](https://imagehosting4picgo.oss-cn-beijing.aliyuncs.com/imagehosting/CleanShot%202026-11-22%20at%2014.17.33%402x.png)



这类“访问其他 App 数据”的提示，可以给 **T3 Code 完全磁盘访问权限**来减少：

1. 打开 **系统设置 → 隐私与安全性 → 完全磁盘访问权限**。
2. 点 **＋**，添加 `/Applications/T3 Code (Beta).app`。
3. 打开开关，再完全退出并重新打开 T3。

这只授权 **T3**，不是给所有软件一键放行；也不会代替辅助功能、录屏、麦克风等其他权限。它允许 T3 访问包括其他 App 数据在内的广泛文件，应确认你愿意授予这个范围。[Apple 说明](https://developer.apple.com/videos/play/wwdc2023/10053/)

当前弹窗点“允许”只是这次请求，**我还没有替你修改权限**。
